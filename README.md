# HELIOS – Tower Defense Game

A strategic, level-based tower defense game set in a stylized ancient Mediterranean world.

## 🎮 Overview

**HELIOS** is a tower defense game where the player defends an ancient polis against enemy invasions coming from both sea and air. The gameplay combines classic tower defense mechanics with strategic map manipulation and unit deployment.

Players must:
- Control enemy paths by building islands
- Place and upgrade towers
- Deploy naval and aerial units
- Manage limited resources effectively

---

## 🧠 Core Gameplay

### 🔁 Gameplay Loop

1. **Build Phase**
   - Use mana to place islands
   - Redirect enemy paths
   - Unlock resource nodes

2. **Defense Setup**
   - Build towers on islands
   - Choose from different tower types:
     - Offensive
     - Support
     - Resource collectors

3. **Combat Phase**
   - Enemies attack in waves (time-based and triggered)
   - Deploy your own units
   - Upgrade towers mid-battle

4. **Progression**
   - Upgrade towers and units in the hub
   - Unlock new abilities and strategies
   - Advance through campaign levels

## ⚔️ Features

- 🏝️ **Dynamic Path Manipulation** – shape enemy routes by placing islands
- 🏗️ **Multiple Tower Types** – offensive, support, and resource-based
- ✈️ **Air & Naval Combat** – enemies attack from multiple dimensions
- 🧩 **Strategic Depth** – unit types, counters, and synergies
- 📈 **Progression System** – upgrades, unlocks, and scaling difficulty
- 🎨 **Stylized Low-Poly Art** inspired by Mediterranean landscapes
